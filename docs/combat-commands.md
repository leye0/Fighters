# Commandes de la scène 3D

- **WASD / flèches** : déplacement horizontal et en profondeur.
- **Espace / J** : saut à 60 Hz.
- **K** : descente volontaire des plateformes traversables.
- **F** : jab (12 dégâts, fenêtre de contact courte).
- **G** : coup croisé (20 dégâts, plus de portée).
- **H** : crochet (16 dégâts, plus rapide, portée réduite).
- **Téléphone paysage** : touches de déplacement, saut, descente et trois attaques.
- **Manette** : stick gauche, A pour sauter, B pour descendre, X/Y/LB pour les trois gestes.

Les touches déclenchent les animations exactes et les dégâts/réactions de la démo. Les ennemis ripostent. Il faut éliminer les deux adversaires ; après victoire ou défaite, utiliser **Rejouer**. Seuls les ennemis **devant** soi et dans le volume X/Z/Y du coup sont touchés ; aucune rotation automatique vers une cible. Les contacts restent à mesurer visuellement avant la production définitive.
