# Commandes de la scène 3D

- **WASD / flèches** : déplacement horizontal et en profondeur.
- **Espace / J** : saut à 60 Hz.
- **K** : descente volontaire des plateformes traversables.
- **F** : jab (clip CC0 prévisualisé).
- **G** : coup croisé (clip CC0 prévisualisé).
- **H** : crochet (clip CC0 prévisualisé).
- **Téléphone paysage** : touches de déplacement, saut, descente et trois gestes.
- **Manette** : stick gauche, A pour sauter, B pour descendre, X/Y/LB pour les trois gestes.

Les trois gestes sont des **animations**, sans dégâts attribués. Les commandes d’un véritable combat seront construites quand l’inventaire des frappes mesurées sera prêt.
