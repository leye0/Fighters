# Lièvres sauvages — modèle externe

Le jeu charge le modèle low-poly **Forest Rabbit** de Polyfork depuis son CDN officiel :

- [Modèle et licence](https://polyfork.dev/asset/forest-rabbit-ea2da0)
- GLB : `https://polyfork.dev/cdn/forest-rabbit-ea2da0.glb`

Le modèle compte environ 2 074 triangles, un matériau et 1,2 Mo transférés une
seule fois. Seize lièvres se partagent les mêmes géométries et matériaux en mémoire.
Le déplacement et les petits bonds sont calculés par le jeu, sans modèle supplémentaire.
