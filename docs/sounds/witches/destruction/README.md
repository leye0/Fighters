The playable original MP3 is not bundled yet. Add the downloaded MP3 as
`Witch_Destruction.mp3` in this folder and rerun the
**Import licensed Witch voice audio** GitHub Action to include it in the
manifest. Do not use the former Pond5 paid preview.

The sound engine treats destruction as an optional category until the
approved MP3 exists; Witch death is silent in the meantime.
