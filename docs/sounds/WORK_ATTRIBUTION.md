# Construction hammer sound

Both `orcs/work/Hammer.mp3` and `witches/work/Hammer.mp3` contain the same
short hammer-on-anvil recording, converted to a 32 kHz mono 64 kbps MP3
(approximately 4.8 KB per copy) for the mobile RTS.

- Original: **Blacksmith's Hammer**, by **VishwaJai**
- Source: https://opengameart.org/content/blacksmiths-hammer
- License: **Creative Commons Zero (CC0)** — attribution not required
- Original file: `blacksmithhammer.mp3` (about 0.55 seconds)

Only the audio format and bitrate were changed. No synthesised hammer sound is used.
